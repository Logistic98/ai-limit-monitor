# 使用文档

## 登录与检查

- Claude 使用 `/login_claude` 获取授权链接。浏览器内完成授权后，如果页面返回授权码，通过 `/login_code claude YOUR_CODE` 发给机器人。
- Codex 使用 `/login_codex` 获取设备登录链接和一次性验证码，在浏览器中输入验证码完成授权。验证码过期时重新发送登录命令。
- 登录后发送 `/check` 查看接入状态。若提示重新登录，用 `/diagnose` 查看凭据是否缺失、是否过期或仍可自动刷新。

## 查询用量

| 命令 | 用途 |
|---|---|
| `/monitor` | 查看已用额度、重置倒计时、续费和重置卡 |
| `/diagnose` | 查看凭据有效期、续费日期和自动任务的计划或失败状态 |
| `/help`、`/ping` | 查看命令或检查 Bot 是否响应 |

报告中的百分比表示对应额度窗口已使用的比例。日期按配置时区显示，倒计时以查询时刻为准，重新发送命令即可更新。

Codex 的凭据到期和订阅续费分别显示。前者用于判断 CLI 登录是否需要刷新，后者用于安排付费订阅的续费提醒。

## 限额恢复

额度窗口重置后，自动任务可通过对应 CLI 发起一次轻量请求，开启新的额度窗口。成功后机器人会推送最新报告。若登录状态失效，自动任务会暂停，重新登录并通过检查后继续。

| 命令 | 用途 |
|---|---|
| `/quota_refresh` | 查看限额恢复任务 |
| `/quota_refresh on`、`/quota_refresh off` | 开启或关闭限额恢复后的自动请求 |
| `/quota_refresh claude`、`/quota_refresh codex` | 立即向指定服务发起一次轻量请求 |

## Codex 续费与重置卡

续费提醒按账号、续费周期和提醒天数去重。服务恢复时若已错过多个时间点，只补发当前最接近续费的一档。提醒天数可在 `.env` 中调整。 [配置说明](configuration.md#监控与续费)

| 命令 | 用途 |
|---|---|
| `/reset_codex_cards` | 查看可用卡片、到期时间和计划使用时间 |
| `/reset_codex_tasks` | 查看已保存的任务、提醒发送状态及失败重试 |
| `/reset_codex_auto on`、`/reset_codex_auto off` | 开启或关闭重置卡自动使用 |
| `/reset_codex_use` | 选择最近到期的可用重置卡并生成一次性确认码 |

手动使用时，在同一会话按机器人回复发送 `/reset_codex_use confirm 确认码`，确认码有效期为 5 分钟。自动使用按配置在卡片到期前安排，只为到期时间明确且可用的卡片创建计划。
